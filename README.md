# 🧾 TASK 8: Regional Category Sales Dashboard

## 📌 Objective
Create a dashboard showing how different categories perform across regions and time.

## 📁 Dataset
File: Sample_Superstore_Sales.csv  
Columns: Order Date, Region, Category, Sales, Profit

## 🛠 Tools Used
- Power BI Desktop

## 🚀 Steps to Reproduce

1. Load the CSV file into Power BI.
2. Add a MonthYear column for monthly views.
3. Visuals to Add:
   - 📈 Line Chart: Sales by Region over time
   - 📊 Tree Map: Sales by Category and Region
   - 🍩 Donut Chart: Sales by Category
4. Enable Filters:
   - Add slicers for both Region and Category
5. Highlighting:
   - Use distinct colors to show which region leads in each category
